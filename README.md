# Projeto_Padaria2_IA_COPILOT

🚀 Destaques do Projeto & Competências Desenvolvidas
Este projeto vai além de uma simples página estática. Ele foi concebido para resolver dores reais de negócios do setor alimentício, unindo experiência do usuário (UX), desempenho e código limpo.

Abaixo estão os principais conceitos e habilidades técnicas consolidados durante a construção desta aplicação:

1. Engenharia de Frontend com JavaScript Moderno (ES6+)

Arquitetura Baseada em Dados (Data-Driven UI): Em vez de duplicar código HTML, utilizei coleções de dados (Arrays e Objetos) para centralizar os itens do cardápio. Toda a renderização da interface é feita dinamicamente via manipulação do DOM.

Manipulação de Array e Métodos de Alta Ordem: Aplicação prática dos métodos .map() para construção dos cards e .filter() para realizar a filtragem por categoria em tempo real, mantendo alta performance e zero recarregamentos de página.

Lógica de Negócio em Tempo Real: Desenvolvimento de algoritmo dinâmico que consome o relógio do cliente via objeto Date(), calculando o estado atual do estabelecimento (aberto/fechado) e alterando a UI dinamicamente.

2. Estruturação, Estilização e Design Responsivo

HTML5 Semântico: Uso rigoroso de tags semânticas para melhorar a acessibilidade (A11y) e a indexação em motores de busca (SEO).

CSS Moderno e Escalável: Aplicação de CSS Custom Properties (Variáveis) para garantir a consistência do sistema de design (Design System) e facilitar a personalização de temas.

Layouts Flexíveis: Construção de interfaces totalmente adaptáveis para celulares, tablets e desktops utilizando uma abordagem mista de CSS Grid e Flexbox.

3. Visão de Produto e Orientação a Negócios (UX/UI)

Foco em Conversão: Integração direta com APIs de comunicação (como mensagens pré-formatadas para o WhatsApp), eliminando atritos no fluxo do cliente até a compra.

Carregamento Otimizado: Implementação de técnicas de performance, como o uso de Lazy Loading nativo em imagens para acelerar a renderização inicial (First Contentful Paint).

💡 Por que este projeto é relevante?
Ele demonstra a capacidade de transformar requisitos funcionais de um cliente real em código modular, legível e de fácil manutenção, pronto para ser integrado a APIs no futuro.
